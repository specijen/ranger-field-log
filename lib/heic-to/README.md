# heic-to 1.6.5 (CSP build)

Unmodified copy of `dist/csp/heic-to.min.js` from the npm package
[heic-to](https://www.npmjs.com/package/heic-to) 1.6.5, source at
https://github.com/hoppergee/heic-to. It bundles libheif and is licensed
under the GNU LGPL v3 (see `LICENSE`). Field Log loads it only when a
HEIC/HEIF photo can't be shown by the browser, to convert it to JPEG on
the phone. To update it, replace `heic-to.min.js` with a newer release
and bump `STATIC_VERSION` in `sw.js`.
